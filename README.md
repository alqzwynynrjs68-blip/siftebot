# نغنوغ — بوت حماية وإدارة مجموعات Telegram

نسخة احترافية باللهجة العراقية لإدارة وحماية المجموعات.

## التشغيل
1. ثبّت Node.js 22.
2. نفّذ `npm install`.
3. أنشئ ملف `.env` وضع:
   - `BOT_TOKEN=توكن_البوت`
   - `OWNER_ID=ايدي_المالك`
4. شغّل: `npm start`

## أهم الميزات
- قائمة رئيسية ثابتة بأسفل محادثة الخاص.
- إدارة إعدادات المجموعات من الخاص بعد اختيار المجموعة.
- حماية الروابط والصور والفيديو والوسائط والصوتيات والملصقات والتحويل والتكرار.
- إنذارات وعقوبات قابلة للضبط.
- ترحيب ورسائل خدمة ومكافحة إغراق ومكافحة البوتات وفلترة كلمات.
- ردود تلقائية عراقية مدمجة + ردود مخصصة لكل مجموعة.
- إضافة/حذف/تفعيل الردود التلقائية من الخاص.
- إدارة الأعضاء وسجل الإدارة والألعاب والنقاط.
- لوحة مالك خاصة تتضمن الإذاعة العامة والاشتراك الإجباري.

ملاحظة: يجب رفع نغنوغ مشرفاً في المجموعة مع الصلاحيات اللازمة حتى تعمل أدوات الحماية والإدارة.
